Upload Candidate List

Candidates are created with status pending

1 · Job
Candidates will be uploaded for this specific job position
2 · File
Accepted: .csv, .xlsx, .xls · max 16 MB
File Requirements
  • Format: CSV or Excel (.xlsx, .xls)
  • Required columns: Name, Email, Job Application Link (column names are not case-sensitive)
  • Optional column: Phone — needed only for the reminder call. Accepts 9876543210, 09876543210, +91 98765 43210 and similar; all are stored as +919876543210. A number that cannot be read is reported as a warning and the candidate is still created.
  • The link column can hold either link type: an application link /jobs/<JOB_ID>/?candidate_id=<ID> or an interview link /interviews/<ASSISTANT_ID>/?candidate_id=<ID>. Both IDs must be valid UUIDs
  • The ID in each link's path must equal the selected job's ID. For interview links, create the job with the assistant ID as its Job ID
  • For a batch, links use the original job's ID, same as every other batch. Upload each batch's candidates into that batch; a candidate can be in only one batch
Sample CSV Format
Name,Email,Phone,Job Application Link
John Doe,john@example.com,+919876543210,https://app.fabrichq.ai/jobs/<JOB_UUID>/?candidate_id=7f3e9a2c-4b1d-4f8e-9a2c-4b1d4f8e9a2c
Jane Smith,jane@example.com,9876543211,https://app.fabrichq.ai/interviews/<ASSISTANT_UUID>/?candidate_id=8a4f0b3d-5c2e-4a9f-8b3d-5c2e4a9f8b3d

Use one link type per job: application links carry the job ID, interview links carry the assistant ID.

Booking Link Format

After uploading candidates, send them slot booking links in this format:

https://slot-booking.fabrichq.ai/book?candidate_id=CANDIDATE_UUID&job_id=JOB_UUID

Example for Software Development Engineer I:

https://slot-booking.fabrichq.ai/book?candidate_id=a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d&job_id=e34e8e92-95ff-47f5-8e2f-86baa397c2a0
The job_id parameter must match the job you selected during upload. Both job_id and candidate_id must be valid UUIDs.
